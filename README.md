# Dinosaurs, free prompt pack

What if dinosaurs were still alive, and friendly? Five AI shots, filmed like 2003
home video. The full prompts and the finished clips.

**Live:** https://ridge-dinosaurs-prompts.vercel.app

Four of the five prompts were run with no reference images at all. Everything in the
picture is written out in the text.

Static site: no build step at serve time, no dependencies. Everything in this repo is
what gets served. The download is `dinosaurs-prompt-pack.zip`.
